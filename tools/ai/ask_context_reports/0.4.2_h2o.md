- Skills: choosing-a-forecaster, forecasting-single-series, backtesting-configuration; 13.4s

The initial training size is set to 2003-04-01 because the default configuration allocates 70% of the 204 observations (142 observations) to initial training. The refit parameter is set to False by default so the model trains only once instead of retraining across each fold, keeping training costs low.

## Initial Training Size

* The cutoff date is 2003-04-01, representing the first 142 observations of the series (70% of the 204 observations).
* This provides a sufficiently long initial training period while leaving enough subsequent observations to evaluate 6 backtesting folds of 12 steps each.

## Refit Setting

* The refit parameter is set to False, resulting in a single model fit (n_fits: 1).
* Setting refit to False is the default behavior because refitting on every fold would multiply training cost across the 6 folds.
* The model is fitted once on the initial training data and used to generate predictions across all evaluation folds without retraining.

### [probe] Why is the gap 0, and why are incomplete folds allowed?

- Skills: choosing-a-forecaster, forecasting-single-series, backtesting-configuration; 8.1s

A gap of 0 indicates that predictions begin immediately following the training data cutoff without any simulated delay between observation collection and forecast generation. Allowing incomplete folds ensures that any remaining data at the end of the series can still be evaluated even if there are fewer observations left than the full 12-step horizon.

## Configuration Rationale

- Gap: With gap set to 0, there is no separation between the end of the training window and the start of the test window. This reflects a setup where forecasts are needed right away as soon as the latest data point arrives, rather than simulating an ingestion lag or pipeline delay.
- Incomplete folds: Setting allow_incomplete_fold to True allows the backtesting process to evaluate a final fold that contains fewer than the configured 12 steps. Without this setting enabled, trailing observations that do not fit into a complete 12-step window would be dropped from the evaluation.
