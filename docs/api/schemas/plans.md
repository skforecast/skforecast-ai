# Plans

The configuration that runs. [`ForecastPlan`][skforecast_ai.schemas.plans.ForecastPlan] is returned by [`plan()`][skforecast_ai.assistant.ForecastingAssistant.plan] and [`refine_plan()`][skforecast_ai.assistant.ForecastingAssistant.refine_plan], and rendered into a script by `forecast_code()` and `backtest_code()`. The other models of this page describe its parts and the overrides that the methods of the assistant accept.
